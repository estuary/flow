# Private and BYOC Deployments

This section provides additional information and guides to help set up [private](../getting-started/deployment-options.md#private-deployment) and [Bring Your Own Cloud](../getting-started/deployment-options.md#byoc-bring-your-own-cloud) deployments.

These deployment options let you use Estuary with your own cloud environment and are especially suited to industries with a strict regulatory landscape.

The main difference between the two deployment models is who owns the infrastructure for the data plane.
* With private deployments, Estuary sets up dedicated compute for your data plane.
* With BYOC deployments, you use your own cloud account (generally separate from your main cloud account) for your data plane.

In both cases, Estuary's control plane orchestrates tasks while only your dedicated data plane actually touches your data.

[Contact us](mailto:support@estuary.dev) to begin the process for a private or BYOC deployment. You will need a license to get started.
