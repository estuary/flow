# WP01: connector-init --vsock-port

## Goal
connector-init can serve its gRPC services over AF_VSOCK, so the reactor
reaches it through libkrun's vsock-to-Unix-socket mapping instead of TCP.

## Read
- CONTRACTS.md: "connector-init".
- `crates/connector-init/src/lib.rs` (Args, `run`, the readiness byte) and
  `crates/connector-init/src/main.rs`. Nothing else in the crate matters.
- PLAN.md is not needed beyond knowing the reactor connects; the guest never
  initiates.

## May touch
`crates/connector-init/**`, `Cargo.lock` (new dependency).

## Design
- `Args`: `port: Option<u16>` and `vsock_port: Option<u32>`, exactly one
  required (clap `ArgGroup`, required). Keep `--port` behavior identical.
- Listener: `tokio-vsock` `VsockListener::bind(VsockAddr::new(VMADDR_CID_ANY,
  port))`. Pick the crate version whose tokio matches the workspace.
- tonic's `serve_with_incoming_shutdown` wants a `Stream<Item = Result<IO>>`
  where `IO: AsyncRead + AsyncWrite + tonic::transport::server::Connected +
  Unpin + Send`. `VsockStream` does not implement `Connected`; wrap it in a
  newtype and implement `Connected` with a unit-like `ConnectInfo`. Build the
  stream with `async_stream` or `futures::stream::unfold` over `accept()`.
- Write the readiness space byte after the bind succeeds, same as TCP.
- Do not touch the proxies, codec, or watchdog.

## Verification
```
cargo build -p connector-init && cargo clippy -p connector-init
mise exec -- cargo nextest run -p connector-init
```
If STATUS.md says `vsock_loopback` loads on this box, add an integration test
that starts the binary with `--vsock-port 49092`, waits for the space byte,
and completes a `Spec` RPC over a `VsockStream` to CID 1 using a tonic client
with a custom connector. If the module does not load, skip the test with a
comment and note in STATUS that WP06 covers it.

## Notes
- The runtime locates `flow-connector-init` via `locate_bin`, which finds the
  freshly built `target/debug/flow-connector-init`. WP05 and WP06 pick up
  your change by building the workspace; no packaging step.
- Keep the TCP path byte-identical. Experiment 3 compares switch-on to
  switch-off, and the off side must be today's behavior.
