# WP07: Egress from inside the guest (experiments 6, 7, 8)

## Goal
Rerun WP02's probe suite from a real guest through the real tap and
ruleset, and add the probes that only make sense with a VM.

## Read
- PLAN.md: experiments 6, 7, 8.
- CONTRACTS.md: "Probes and benchmarks", "Helper CLI" (`--exec`,
  `--run-as-root`), "flow-init" (`--as-root-exec`), "Policy JSON".
- STATUS.md entries for WP02 and WP06.

## May touch
`spike/tasks/exp{6,7,8}-*.sh`, `spike/egress/probes.py` (additions only),
`spike/report/exp{6,7,8}.md`, `spike/report/data/`.

## Steps
- First, rerun experiment 4 under the real ruleset: `spike/tasks/exp4-derive.sh`
  with `spike/catalog/policy-allow-all.json` once WP02's binaries are in the
  helper image. Update `report/exp4.md`'s gate line from "under an unenforced
  network" to the result. This closes the provisional in PLAN's gate table.
- Timing inside the guest uses the guest's own clock; guest stderr reaches
  the host ~290 ms late (WP06). Probes report `ms` from `time.perf_counter`.
- Two passes per policy set: `--run-as-root` for the root probes
  (`icmp-blocked`, `spoofed-source`; `probes.py --root-probes auto` includes
  them only when euid is 0) and a plain pass for everything else.
- Spoof with a source INSIDE the tap's /30 (`192.0.2.3`) so the packet passes
  any inherited `rp_filter` and reaches the nft anti-spoof rule, whose
  counter is then the evidence. The helper inherits the host's `rp_filter`;
  record its value (`/proc/sys/net/ipv4/conf/tap0/rp_filter` inside the
  helper). A zero counter with a strict `rp_filter` is not a failure.
- Rate limit reads as pacing, not errors (PLAN experiment 8, rewritten):
  assert the sustained rate and the fan-out timeout, not refusals.
- `spike/egress/testnet.py` is the short-TTL name and the idle-holding server
  the TTL probes need. Run it on the host, reachable from the helper on the
  `flow-connectors` gateway address, and point the helper's resolver at it:
  add a spike-only `--resolver-upstream IP:PORT` to the shim's CLI (the one
  shim change this package may make) that overrides the `/etc/resolv.conf`
  upstream the shim otherwise passes.
- `examples/declared.json` fails to load on the HOST because the host owns
  `198.51.100.0/24`; inside the helper it loads. Run the binaries where they
  run in production.
- `none` mode latencies from the netns run: DNS ~20 s, TCP connect bounded
  only by the probe's own cap (a dropped SYN takes ~127 s to fail). Report
  "at least the cap used".
- Put `probes.py` under the venv directory (`<venv>/spike/probes.py`) and
  invoke the guest with `--exec /usr/local/bin/python /venv/spike/probes.py
  <set> <targets...>` via the fake reactor, one policy file per set.
- The RFC1918-answer probe uses a sibling container's name (`spike-nginx`
  is on a different network; run a throwaway container on
  `flow-connectors` and resolve its name through the helper's resolver).
- The "bridge gateway on the reactor's port" probe: gateway IP of
  `flow-connectors` from `podman network inspect`; port from whatever the
  fake reactor's flowctl is listening on, or any host port that is open.
- Spoofed-source UDP: the helper's `--as-root-exec CMD` (passed through to
  flow-init) runs a python one-liner that sends a raw UDP datagram with
  source `192.0.2.3` before the uid drop.
  Prove the drop with a counter on the anti-spoof rule and `tcpdump -i
  eth0` inside the helper showing nothing.
- Guest listener: `--exec` a python listener; `podman exec <helper> socat -
  TCP:192.0.2.2:PORT` must fail.
- "No packet leaves the helper" for every must-fail: run `tcpdump -i eth0
  -w` inside the helper for the probe's duration and assert no packet to the
  probe's destination. Also snapshot `nft list ruleset` counters.
- TTL probe: use a name you control with a short TTL, or point the resolver
  at a tiny authoritative stub on the host for that one probe; either way
  record how you did it. Expect the 90-second floor per CONTRACTS.
- Experiment 7: `egress: none` policy; record the seconds each failure took
  to surface (this is the accepted cost PLAN mentions).
- Experiment 8: the two limits; report the nft constructs verbatim.

## Verification
All probes pass in all sets; `report/exp6.md`, `exp7.md`, `exp8.md` with the
pass line first, then the probe table (probe, expected, observed, ms,
packets-left-helper).

## Out of scope
Changing the ruleset design. If a probe fails because the ruleset is wrong,
fix it in `spike/egress/` and record it as a WP02 deviation.
