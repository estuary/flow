# WP08: virtiofs import matrix (experiment 5)

## Goal
The number that decides whether the image can be served over virtiofs, and
the variants that say what to do if it can't.

## Read
- PLAN.md: experiment 5 and the "Decision" bullet for experiment 5.
- CONTRACTS.md: "Helper CLI" (`--exec`, `--venv-dax`, `--thp-disable`),
  "Probes and benchmarks", "Paths and names" (derived image name).
- STATUS.md entries for WP03, WP04, WP06.

## May touch
`spike/derived/**`, `spike/tasks/exp5-*.sh`, `spike/report/exp5.md`,
`spike/report/data/`.

## Steps
1. `spike/derived/Dockerfile`: `FROM` the derive-python image, create
   `/opt/venv` with `uv venv` and `uv pip install pandas` (pin the version),
   readable by `nobody`. Build as `localhost/derive-python-pandas:spike`.
   Also export the same venv to a host directory (build it inside a
   container of the same image so the interpreter matches) for the
   separate-share variant.
2. `bench.py` under the venv dir: measures with `time.perf_counter` (a) the
   wall time of `import pandas` in-process, (b) `subprocess.run([python,
   "-c", "pass"])`, and prints JSON. Invoked as the guest workload via
   `--exec`. The same script runs the baseline under plain `podman run`.
3. Cells, 10 fresh guests each (guest cache cold; warm the host cache with
   one throwaway run per cell first):
   - primary: derived image as root, venv at `/opt/venv`
   - share: derive-python image as root, venv dir as the `venv` share,
     `import` from `/venv`
   - share+dax: same with `--venv-dax`
   - each of the above with and without `--thp-disable`
   - baseline: `podman run --rm localhost/derive-python-pandas:spike python
     /path/bench.py`, 10 fresh containers
4. If overlayfs-over-virtiofs is a suspect, one extra cell with a flow-init
   flag that skips the overlay (add it, record it) isolates that layer.

## Verification
`report/exp5.md`: the gate line (primary import median vs baseline, the 2x
test), then the full matrix as a table (cell, median ms, p95 ms, n). Note
explicitly that root DAX is unavailable in libkrun 1.19 and what the share
variants imply for the layer-vs-share decision.

## Out of scope
Changing the helper or flow-init beyond flags needed for the cells.
