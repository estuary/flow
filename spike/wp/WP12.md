## Side item first
WP09 found two bugs in existing buttons, both live since they were written:
`helper-smoke.sh` asserted an nft table once, in a ~30 ms window before the
shim had loaded it (green four runs in five); and `exp13-crash.sh` ran a
`kill` on an already-dead pid as the last command of an `&&` list inside a
function the EXIT trap calls, which under `set -e` aborted the trap, so
cleanup never ran and the script printed `ok` while exiting 1. Sweep every
`spike/tasks/*.sh` for exactly those two shapes: a command that may fail as
the last step of an `&&` list or a bare statement inside anything a trap
calls; and a single-shot assertion on state the shim or podman sets
asynchronously after the container becomes executable. Fix what you find
the way WP09 did (`|| true`; poll with a bound), rerun only the buttons you
touched, and list them in STATUS. Bounded to those two shapes: no
restructuring, no folding of the `*-common.sh` files.
