# WP00: Environment

## Goal
Make this GCP box able to run every later package with one command, matching
production's podman version and launch topology.

## Read
- PLAN.md: "Inputs established before the spike", "Environment".
- CONTRACTS.md: "Paths and names", "Fake reactor".
- Nothing under crates/.

## May touch
`spike/tasks/env-*.sh`, `spike/tasks/fake-reactor.sh`, `spike/tasks/nginx/`.

## Deliverables
1. `spike/tasks/env-setup.sh` (idempotent, uses sudo):
   - `apt install podman uidmap slirp4netns netavark aardvark-dns`; confirm
     `podman --version` is 4.9.3 (noble candidate). Docker is also installed
     on this box; leave it alone, they coexist.
   - `systemctl enable --now podman.socket` so `/run/podman/podman.sock`
     exists (rootful). Production's reactor talks to exactly this socket.
   - `podman network create flow-connectors` (defaults) and
     `podman network create --subnet 198.51.100.0/24 spike-testnet2`.
   - nginx per CONTRACTS on `spike-testnet2` at `198.51.100.10`: self-signed
     cert generated into `spike/tasks/nginx/`, config serving `/` and
     `/probe` (1 KiB file) on 80 and 443. Container name `spike-nginx`.
   - Pull: the reactor image at the tag production runs (see the Quadlet
     `Image=` line in PLAN inputs; if it has been GC'd, the newest
     `ghcr.io/estuary/reactor` tag), `ghcr.io/estuary/derive-python:dev`
     or its current tag, `ghcr.io/estuary/source-hello-world:dev`,
     `ghcr.io/estuary/materialize-sqlite:dev`, `docker.io/library/busybox`,
     `docker.io/library/nginx`. Record the digests in STATUS.
   - `mkdir -p /var/tmp/flow-spike/reactor` and confirm the filesystem is
     ext4 or xfs (`stat -f -c %T`).
   - Try `modprobe vsock_loopback`; record whether it loads (WP01 uses it).
2. `spike/tasks/env-check.sh`: read-only checks for everything above,
   non-zero exit with a one-line reason per failure. Later packages call
   this first.
3. `spike/tasks/fake-reactor.sh CMD...` per CONTRACTS "Fake reactor". Use
   `sudo podman run --rm -i --network=host --user root:root --no-hosts
   -v /run/podman:/run/podman -v $SPIKE_REACTOR_DIR:$SPIKE_REACTOR_DIR
   -v <repo>/target:/flow-target -e CONTAINER_HOST=... -e DOCKER_CLI=podman
   <reactor image> CMD...`. No `--cap-add`, no `--privileged`, no `--device`.
   Pass through every `FLOW_SANDBOX_SPIKE_*` variable present.

## Verification
```
spike/tasks/env-setup.sh && spike/tasks/env-check.sh
spike/tasks/fake-reactor.sh podman ps            # lists host containers (spike-nginx)
spike/tasks/fake-reactor.sh grep CapEff /proc/self/status   # 00000000800405fb
curl -sk https://198.51.100.10/probe | wc -c     # 1024, from the host
```
The CapEff value is production's, decoded in PLAN inputs.

## Out of scope
Building any image or binary. libkrun. nftables rules.
